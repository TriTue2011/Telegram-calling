Gateway đang ở chế độ giả lập: đăng nhập và gọi chưa thật. Muốn chạy thật, ghi TELEGRAM_API_ID, TELEGRAM_API_HASH vào .env, đặt GATEWAY_MOCK=0 rồi khởi động lại container.
